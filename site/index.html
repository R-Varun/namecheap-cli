A small tool for a real task

Let the agent use a CLI.
Keep the change easy to inspect.

01 / INSPECT

One JSON result.

Records, diffs, errors, and exit codes have a clear format. Run namecheap schema to discover the commands.

02 / APPLY

Preview before a write.

Review the diff, then confirm with the observed state hash. Local locks keep CLI writers from overwriting each other.

03 / RECOVER

A backup before submission.

If a request cannot be verified, the result points to the saved state and recovery journal. No automatic write retries.

What it covers

DNS automation.
A clear, bounded scope.

For AI agents, deployment scripts, and people who want to manage Namecheap DNS without maintaining their own API wrapper.

  • BasicDNS records, including A, AAAA, CNAME, MX, and TXT
  • Nameserver delegation and domain availability checks
  • Domain allowlists and separate sandbox credentials
  • Zero runtime dependencies; Python 3.11+
First public beta. Tested offline with a local API and concurrent processes. Authenticated provider writes remain unverified. Unsupported DNS settings block writes. No domain purchases or transfers.
