Built for whole-zone replacement safety

Namecheap's API overwrites every host record at once.
This CLI makes every write safe to automate.

01 / DETERMINISTIC JSON

Self-describing contract

Every command emits one versioned JSON document on stdout—including invalid flags and provider errors. Run namecheap schema for full command discovery and error semantics.

02 / GUARDED TRANSACTIONS

State hashes & local locks

Writes hold an account/domain lock, validate your preview's SHA-256 state hash, re-read before submission, preserve email routing metadata, and verify every record and TTL afterward.

03 / RECOVERY & LIVE DOH

Backups & propagation checks

A 0600 backup and journal entry are written before any submission. Restore with namecheap restore, and confirm public resolution via namecheap dns check.

Agent-ready out of the box

Drop into Claude Code, Codex, Cursor, or CI.

Ships with a portable SKILL.md, machine-readable schema.json, llms.txt, stdin zone piping (dns apply example.com -), domain allowlists, and strict production/sandbox credential isolation.

  • BasicDNS Manage A, AAAA, ALIAS, CNAME, MX, MXE, NS, TXT, and URL/URL301/FRAME records.
  • Delegation Inspect and switch between Namecheap BasicDNS and custom nameservers with backup protection.
  • Live DoH Compare Namecheap's stored zone against Cloudflare public DNS-over-HTTPS via dns check.
  • Bounded scope Blocks writes when unknown email modes or unsupported dashboard settings appear—never buys or transfers domains.
